1. Paper title

Competing leaders grey wolf optimizer and its application for training multi-layer perceptron classifier

2. Paper citation in Vancouver format

Yang Z. Competing leaders grey wolf optimizer and its application for training multi-layer perceptron classifier. Expert Systems with Applications. 2024;239:122349. doi:10.1016/j.eswa.2023.122349.

3. Problem statement

Training a Multi-Layer Perceptron (MLP) requires determining the optimal synaptic connection weights and biases to minimize classification cross-entropy error. This is a non-convex, multimodal optimization problem prone to local optima entrapment and high-dimensional stagnation. Standard Swarm Intelligence algorithms such as Grey Wolf Optimizer (GWO) suffer from premature convergence due to an inflexible leadership hierarchy of only three fixed leaders and delayed generational updates. The paper proposes the Competing Leaders Grey Wolf Optimizer (CGWO), introducing dynamically shrinking competing leaders, compact real-time leader updates, and diversity-enhanced population initiation to train MLPs faster and more accurately without manual hyperparameter tuning.

4. Input data
  • Decision Variable: Continuous search agent vector encoding all concatenated weights and biases: v = [W1 (I×H), W2 (H×O), θ1 (H), θ2 (O)] ∈ [-10, 10]D, with dimension D = (I + O + 1)H + O ranging from 75 to 2775 variables across benchmark datasets (H = 2I + 1).
  • Classification Dataset: Input feature matrix X ∈ RZ×I min-max normalized to [0, 1] (Eq. 19), with ground truth labels Y'.
  • Objective / Fitness Function: Average Cross-Entropy Error (CEE):
    Binary (Eq. 4): CEE = - (1 / Z) ∑ [ y'_i ln(y_i) + (1 - y'_i) ln(1 - y_i) ]
    Multi-class (Eq. 5): CEE = - (1 / (Z · Q)) ∑∑ [ y'_{i,j} ln(y_{i,j}) ]
  • Algorithm Settings: Population size N = 200, max function evaluations FEs = 4.0 × 104, stratified 5-fold cross-validation.

The optimal weight and bias vector v* that minimizes the average training cross-entropy error (CEE), maximizing both training and test classification accuracies for the target dataset.

7. Whether you were able to completely mimic the paper implementation. (Y/N)

N

Justification of Differences: The original study was implemented in MATLAB 2015a under Windows 7 on a 3.40 GHz CPU and evaluated 11 UCI datasets over 10 independent runs of 5-fold cross-validation (550 runs total). Our implementation was created in Python 3.14 using vectorized NumPy and SciPy under Linux. Due to practical computational resources, we implemented and evaluated 4 representative UCI benchmark datasets spanning both binary and multi-class tasks across various dimensional scales: Wine (D=462, Q=3), Seeds (D=168, Q=3), Breast Cancer Wisconsin (D=210, Q=2), and Zoo (D=799, Q=7) across 3 independent runs of 5-fold cross-validation (15 folds per algorithm). Network architectures (hidden layer 2I+1), sigmoid/softmax activations, IPDE initialization, CWLU real-time leader replacement, and dynamic leader shrinkage were completely replicated.

8. Optimization algorithm used

Competing Leaders Grey Wolf Optimizer (CGWO), incorporating:

  • Competing Leaders Mechanism: Adaptive leader group size M shrinking linearly from M_max (Eq. 13) down to M_min = 3 over the first 75% of iterations (Eq. 12). Positions are updated via mean filtering across all M leaders (Eq. 16).
  • Compact Wolf Leaders Update (CWLU): Leaders are updated greedily immediately after each wolf is evaluated, providing real-time guidance without generational delay.
  • IPDE Population Initiation: Combines N uniform random individuals with N sinusoidal chaotic individuals (r_k = sin(π r_{k-1})) and selects the best N from their union (Algorithm 3).

Baseline Algorithm: Canonical Grey Wolf Optimizer (GWO) with 3 fixed leaders (α, β, δ) and generational updates (Algorithm 1).

11. Any improvement obtained when compared to Paper results

Yes

Algorithmic Changes Made to the Existing Paper: We implemented an enhanced variant named Tent-Cosine CGWO (TCGWO) with two targeted improvements:

  • Tent Chaotic Map in IPDE Initialization: The paper's sinusoidal chaotic map (r_k = sin(π r_{k-1})) exhibits an arcsine distribution concentrating near the edges (r → 1), under-sampling the interior search space. We replaced it with the Tent Chaotic Map:
    r_k = 2 · r_{k-1}   (if r_{k-1} < 0.5)   else   2 · (1 - r_{k-1})
    The Tent map possesses an exact uniform invariant density over (0, 1), providing true ergodicity and well-dispersed initial weights across high-dimensional MLP parameter spaces.
  • Nonlinear Cosine Decay Schedule for Competing Leaders M(t): The paper uses a piecewise linear schedule (Eq. 12) where leader count drops immediately from iteration 1. We introduced a smooth Cosine Competition Schedule:
    M(t) = round( M_min + 0.5 · (M_max - M_min) · [1 + cos(π · t / (0.75 · T_max))] )   for t < 0.75 T_max
    Because dM/dt → 0 as t → 0, this retains a broader pool of competing leaders during early exploratory search, preventing premature loss of promising search centers before smoothly transitioning to exploitation (M_min = 3).

Quantitative Improvements Obtained:

  • Breast Cancer: TCGWO decreased median CEE from 0.0298 (CGWO) to 0.0270 (a 9.4% error reduction) and improved training accuracy from 99.03% to 99.14% with faster runtime (17.44 s vs 22.11 s).
  • Seeds: TCGWO reduced median CEE from 0.0159 (CGWO) to 0.0156, while elevating training accuracy from 98.33% to 98.81% and reducing runtime from 14.05 s to 12.04 s.
  • Wine & Zoo: Both algorithms maintained zero error (CEE = 0.0000, 100.00% training accuracy).
